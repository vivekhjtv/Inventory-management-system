## Security & Privacy: Environment Variables (.env) Protection

> [!IMPORTANT]
> **STRICT SECURITY DIRECTIVE FOR ALL AGENTS**:
> 1. **DO NOT READ OR ACCESS `.env`**: Under NO circumstances should any AI agent read, view, grep, search, inspect, edit, or log any `.env` file (including `.env`, `.env.local`, `.env.production`, `.env.development`, or any `.env.*` file).
> 2. **NO LEAKING CREDENTIALS**: Agents must NEVER display, log, or expose passwords, database connection strings, JWT secrets, session keys, or API tokens.
> 3. **USE `.env.example` ONLY**: Whenever demonstrating or configuring environment variables, agents must only reference or generate sample `.env.example` files containing dummy placeholders (e.g. `DATABASE_URL="postgresql://user:password@host:5432/dbname"`).
